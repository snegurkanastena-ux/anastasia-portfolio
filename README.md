# pro-sites-rf-site

Готовая статическая страница для переноса на домен `про-сайты.рф`.

## Что внутри

- `index.html` — готовая страница сайта.
- `styles.css` — стили и адаптивная верстка.
- `assets/neuroera-visual.png` — визуал НейроЭры для первого экрана.

## Что перенесено

- Первый экран с новым оффером.
- Блок «С чего начать?».
- Блок полезных ссылок на закреп Telegram.
- Услуги и цены.
- Портфолио: ИИ-коуч по трансформации, OpenClaw-бот Кузя, Rankofe, стикеры для бизнеса.
- Услуга «Стикеры для бизнеса» от 2 000 ₽ с упоминанием Telegram, MAX и Битрикс.

## Как внедрить на `про-сайты.рф`

Если текущий сайт статический, загрузить содержимое этой папки в корень сайта.

Если сайт на Vercel, создать проект из этой папки или перенести `index.html`, `styles.css` и папку `assets` в текущий проект. После публикации проверить:

- `https://про-сайты.рф` открывается без ошибки;
- кнопка Telegram ведет на `https://t.me/neiroeraMelnikova`;
- кнопка полезных ссылок ведет на `https://t.me/neiroeraMelnikova/884`;
- все цены совпадают с новой линейкой.
